스마트 사이버대학교 UI/UX 인터랙티브 프로토타입

실행 방법
1. index.html을 Chrome, Edge, Safari 등 브라우저에서 엽니다.
2. 왼쪽 메뉴 또는 모바일 상단 ☰ 버튼으로 화면을 이동합니다.
3. 상단 언어 선택에서 한국어, 영어, 중국어, 베트남어 전환이 가능합니다.
4. '간편 모드'를 켜면 글씨와 조작 영역이 커집니다.

시연 가능한 기능
- 대학 포털 / 입학 및 전공 선택 안내
- 학생 대시보드 / 과정별 진도 표시
- LMS 강의 선택 및 학습 완료 처리, 퀴즈
- 수강신청 추가 및 취소 (최대 9학점)
- 증명서 미리보기 및 신청 기록
- 학사일정, 학점/졸업 진단, 휴복학 등 신청 기록
- AI 튜터의 예시 질문/응답
- 브라우저 로컬 저장, 데모 데이터 초기화

주의
본 파일은 HTML/CSS/JavaScript 단일 파일로 동작하는 UI/UX 시제품입니다.
서버, 대학 실제 학사시스템, VOD, 결제, 인증, 생성형 AI와 연결되지 않았습니다.
기본 학사정보와 AI 답변은 모두 예시입니다.
